CSS Selectors Practice

This page uses different types of CSS selectors.

Element Selector

Headings and paragraphs are styled using element selectors.

Class Selector

All the cards on this page share the same class called card.

ID Selector

This card is styled differently using its unique ID.

Conflicting Rules

This text has conflicting rules. The ID selector wins over the class selector because it has higher specificity.
